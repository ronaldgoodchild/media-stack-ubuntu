👋 Start here

This box runs your media library end to end: it finds new movies/shows, downloads them, organizes them, and streams them to any device — TV, phone, browser, whatever. You don't need to touch most of these apps day-to-day. Two things cover 95% of what you'll actually do:

  • Want to watch something you already have? Open Jellyfin (the 🎞️ card above) — it's your Netflix-style library.
  • Want something that isn't in the library yet? Open Seerr (the 🙋 card above), search for it, hit Request. It downloads and organizes itself automatically — no need to touch Sonarr/Radarr/Prowlarr directly.
⚙️ How it fits together

If you're curious what's actually happening behind a request, the chain looks like this:

Prowlarr (searches indexers) → Sonarr / Radarr / Lidarr / Readarr / Whisparr (decide what to grab and where it goes, one per media type) → SABnzbd or qBittorrent (actually downloads it) → Bazarr (finds subtitles) → Jellyfin (organizes and streams it). Seerr sits on top of all of it as the simple "just search and click" front door. ARR Dashboard is a single page that shows what every one of those apps is doing at once, if you ever want the full picture instead of clicking through each one.

🔑 Logins

The *arr apps, Bazarr and SABnzbd share one login, set when you ran tools/wire-stack.py: username media and the random password it printed (also saved in credentials.txt in the install folder on the server). Keep that file private.

💻 Map a network drive (Windows)

File Explorer → address bar → type \\this-server\Media (or \Downloads / \Shared) → sign in with your Samba user and password. Right-click → "Map network drive" to make it permanent. Exact paths with a copy button are on the Dashboard tab.
